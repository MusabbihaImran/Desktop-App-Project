# Changelog

All notable changes to this project will be documented in this file.

## [v1.0] - Launch
- Added complete UI with vibrant dark theme, rounded borders, and custom colored tabs.
- Finalized gallery view with thumbnail rendering and colored borders by item type.
- Integrated comprehensive database tracking for all artworks, filters, and patterns.

## [v0.4] - Generative Patterns
- Added Pattern Maker module using NumPy for math-based rendering.
- Implemented Mandala, Truchet, Checkerboard, and Wave interference patterns.
- Included customizable vibrant defaults and interactive sliders.

## [v0.3] - Color Theory Lab
- Created interactive Color Theory lessons.
- Added Tkinter Canvas color wheel.
- Added interactive color theory quizzes tracking scores in the SQLite database.

## [v0.2] - Image Filters
- Added Pillow-based image filtering lab.
- Implemented Grayscale, Invert, Blur, Sharpen, Emboss, Edge Detect, Sepia, and Pixelate filters.
- Added side-by-side preview functionality.

## [v0.1] - Core Canvas & Database
- Initialized base application with custom dark theme colors.
- Created `canvas_editor` with 32x32 to 64x64 grid drawing capability.
- Added SQLite initialization, logging, and exception handling framework.
