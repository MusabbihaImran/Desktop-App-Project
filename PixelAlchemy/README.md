# PixelAlchemy

PixelAlchemy is a feature-rich desktop art and creativity tool built with Python and Tkinter. It combines a pixel drawing canvas, image filters, color theory lessons, and a generative pattern maker into one polished experience.

## Features
- **Canvas Editor**: 32x32 to 64x64 grid-based pixel drawing.
- **Filters Lab**: Apply various image processing filters.
- **Color Theory Panel**: Learn and test your color knowledge.
- **Pattern Maker**: Generate math-based patterns.
- **Gallery**: View your creations.
